Policy Amendment
How to Use
  1. Select the Contract State.
  2. Select the form being amended.
  3. Enter the applicable question or section.
  4. Select an amendment template.
  5. Complete any required fields.
  6. Review the generated amendment.
  7. Click Add Amendment to save it to the Review Output Package.
Agency Requirement
How to Use
  1. Select a requirement template.
  2. Complete any required fields.
  3. Review the generated requirement.
  4. Copy the wording for case communication.
  5. Click Add Requirement to save it to the Review Output Package.
  6. Click ♡ to save frequently used requirements as Favorites.
